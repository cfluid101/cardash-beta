# Provenance and scope

GPL-3.0-only; see LICENSE. The receiver protocol is a phone-resident port of the isolated CarDash receiver, derived from DiPlay commit `615b32ce0b40cd0b99ce94ba23a512001553684f` and its verified 0.2.22 release: https://github.com/shihabal3amri/DiPlay . Relevant upstream components include PairSetup, PairVerify, Srp6a, AirPlayCrypto, MfiSapAuthSetup, AirPlayInfoPlist, AirPlayHid, NtpClock, ScreenStream and AirPlaySession. DiPlay derives from shilapi/xcertplay. No DiAuto/DiPlay UI implementation is included.

The authenticated control/video parsers and MP4 remuxer originate in the separately preserved CarDash native lab. Audio protocol work also references upstream AudioStream, CarPlayMediaEngine and MicrophonePacketizer. The AAC decoder bridge calls the device's AudioToolbox framework; no Apple library is redistributed. Browser PCM scheduling and bounded transport are implemented in this repository. The native probe reuses Common, NativeIdentity and HostPayload from CarDash diagnostics. The OpenSSL 3 bridge links the bootstrap's libssl3; OpenSSL is not redistributed in this DEB. Python is an external bootstrap dependency. Host-only browser tests use ws under its MIT license and do not ship in the DEB.

No Apple framework, firmware asset bundle, upstream APK, accessory private key, paired phone identity, host SSH key or raw device report is included in this DEB/source release. The user's explicit Prepare action downloads a pinned upstream APK for local experimental identity provisioning, with TLS, SHA-256 and certificate/key checks. Public availability does not confer Apple certification. Product identity provisioning remains an open requirement before a general release.
