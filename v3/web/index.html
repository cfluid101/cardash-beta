CarDash V3 Beta 5Connecting to iPhone…

Native CarPlay, from your iPhone.

Open CarDash V3 on the phone and tap Prepare CarPlay once. Then press Start here.

Controls hide after the first frame. Tap the left-edge arrow beneath the clock to show them again. Browser size changes only scale the current image; use Resize display to fit a new native layout. Resizing briefly restarts the display and audio.

Device output uses the iPhone’s current speaker or Bluetooth route. Changing the Audio choice reconnects CarPlay. Microphone and Siri voice input are not supported.

Use a trusted Personal Hotspot: connected devices can control this preview. Your original CarDash installation stays separate.
