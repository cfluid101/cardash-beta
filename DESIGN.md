# One-install CarPlay diagnostic

User authorized a separate diagnostic DEB that aggregates diagnostics and attempts native session startup. Preserve original CarDash/project/preferences. No phone connection or installation during development. Package ID `com.cfluid.cardash.diagnostics`, app `CarDash Diagnostics`, rootless paths owned exclusively by this package. No injection, respring, network exposure, pairing-record edits, firmware changes, or release-beta replacement.

One app button starts a bounded suite through an on-demand root helper. A new immutable-name log captures install status, device/build, method encodings/owners, private-framework inventory, system service logs, session state, socket requests, timeout/crash/cancellation and cleanup. Share exports one `.log`; tests can be rerun without reinstalling. A helper failure must still yield a shareable app/install diagnostic.

Root helper accepts only RUN/STATUS/CANCEL from the exact installed app or its own root CLI; launchd supplies a local Unix socket. Fixed worker profiles run in isolated children with per-stage and whole-suite deadlines. Child death/timeout must be recorded and reaped. Runtime size caps preserve a terminal summary. No downloaded accessory identity is included.

Active profiles compare the retained canonical simulator request with no-public-key, non-simulator and mobile-identity variants. All private calls require the recorded iPhone10,2/iOS16.6/20G75 target, expected ABI and implementation owner. Existing CarPlay sessions block active attempts. Each profile owns only its request client and an IPv6-loopback listener, invokes the known `startSessionWithHost:completion:` once, then calls `cancelRequests`. Completion block arguments remain uninterpreted because their contract is not established. Loopback request metadata is recorded; authentication is explicitly unimplemented and must never be called successful. Transport, callback, authentication, activation, display and live-video conclusions remain distinct.

Local evidence: native cross-compile/signature/package audit, real host helper/socket/process/log tests including cancel/hang/crash/oversize output and repeat runs, ABI/classification tests, simulator app smoke if the installed runtime works, and a fresh independent final review. No 100% device-compatibility promise; local checks cannot prove private runtime success.
