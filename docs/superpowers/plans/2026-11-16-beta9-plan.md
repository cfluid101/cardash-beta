# Beta 9 implementation plan

1. CarKit owner: extend HostProfile, SessionInspection and SessionProbe with
   independent exact profiles, request ABI choice, constructor/archive guards,
   bounded error details and fixtures for unknown or altered implementations.
2. Transport owner: encode per-profile offsets and lifecycle; reject 19A346
   before mutation, add middle and shifted profiles, preserve legacy behavior,
   test ownership, mapping, fingerprints and negative identities.
3. Media owner: decouple CPU from video ABI, profile state offsets, guard new
   NetworkInfo state, add exact audio setters and independent byte/address tests.
4. Integration owner: compatibility_summary(inventory, inspection, status)
   returns one bounded diagnostic-only record. Exercise missing injection,
   unknown identity, signature failure, mismatched publisher PID, optional audio,
   missing helper and successful-readiness-without-device-validation cases.
   Export it with independent read-only inspection. Record failed startup gates
   without spawning a helper or applying leases. Retain offline app diagnostics.
5. Build owner: beta 9 version/minOS15.0, truthful target manifest and docs. Reuse
   verified iOS15 OpenSSL input. Compile/sign, run native/Python/browser/reference
   suites and package audits. Independently review adapter regression risks.
6. Commit final source, build exact commit, archive source, record hashes and
   copy tester artifacts to FluidDrive. Verify beta8 baseline and IPSWs unchanged.

Review focus: wrong-layout object writes; authenticated arm64e entry handling;
silent success from missing/stale readiness; mixed iOS17 component generations;
unknown firmware mistaken for supported; credentials in failure exports.
