# Provenance

This diagnostic was implemented in the user's separate CarDash update/research copy. The known iOS 16.6 selector/encoding and loopback-host contracts were checked against the user's retained `carplay-loopback-m3` device evidence (M4 and M5). Those files were read only; their earlier no-callback/no-transport result is historical evidence, not a result from this package.

No Apple framework, firmware, proprietary accessory identity/private key, CarBridge implementation, or third-party UI artwork is packaged. The icon is an original geometric diagnostic asset. The generated public key has no retained private counterpart and cannot complete accessory authentication. This package does not reuse the synthetic H.264 lab as evidence of native CarPlay success.
